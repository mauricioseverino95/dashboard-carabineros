Activar descargas en este equipo

Las descargas las hace el descargador del dashboard en GitHub. Para que este equipo pueda iniciarlas, pegue aquí un token de acceso de GitHub (solo se guarda en este navegador).

  1. Abra github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → dashboard-carabineros.
  3. Permissions → Repository: Actions: Read and write y Contents: Read-only.
  4. Genere el token, cópielo y péguelo abajo.
